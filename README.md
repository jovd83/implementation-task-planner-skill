`implementation-task-planner-skill` turns approved product and architecture artifacts into executable engineering tasks.

## What It Produces

- `tasks.md`
- optional `tasks.json`
- dependency map
- parallel task groups
- validation command list
- skill route map

## Usage

```text
Use $implementation-task-planner-skill to turn this architecture plan and acceptance criteria into ordered implementation tasks.
```
