# Team Availability Widget

## Goal

Show whether teammates are available before assigning work.

## Known Acceptance Criteria

- AC-001: A user can see an availability indicator next to each teammate in the assignment panel.
- AC-002: The indicator must distinguish available, busy, and unknown.

## Unknowns

- The source of availability data has not been selected.
- The API contract is not approved.
- The UI framework and test runner for this project are not confirmed.
